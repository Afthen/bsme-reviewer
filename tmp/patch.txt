Found the root cause of the `fetch failed` error in Node:

`test/run_test.js` sets `globalThis.window = globalThis` (for headless UI tests), and Node 22 provides `globalThis.fetch` (undici), which does not implement `file://` URLs. Because `src/mcq/index.js` (generated by `scripts/gen_registry.js`) checked `typeof window !== "undefined" && typeof fetch === "function"`, `loadMcqSet` attempted `fetch("file:///...")` in Node instead of reading via `node:fs`.

Detecting Node via `typeof process !== "undefined" && process.versions?.node` (or `fileUrl.protocol === "file:"`) ensures Node always uses `node:fs` even when `globalThis.window` is mocked, while browsers over HTTP/HTTPS use `fetch(fileUrl)`.
